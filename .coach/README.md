# AD265 Cline coach (reference solutions)

This folder holds one **raw patch per exercise** (`exN.diff`) — the exact code
change for that exercise. The in-workshop Cline coach (see `../.clinerules/`)
reads these **on demand**, only when it reaches the "show the solution" stage, so
it can guide toward or reveal the solution for the exercise a participant is on.

## Where they come from — do not hand-edit

`exN.diff` are generated by `../.gen-coach.sh` from exercise checkpoint **tags** in
this repo (the single source of truth):

```
base          # starter state participants clone (= main)
ex2-solution  # state after exercise 2
ex3-solution
ex4-solution
```

(Exercise 1 has no code change, so it has no checkpoint and no diff.)

To regenerate after changing the solution code + tags, run from the repo root:

```
./.gen-coach.sh
```

Each diff is scoped to exactly what that exercise's README describes — editor
noise and incidental tweaks are intentionally excluded. The per-exercise summary
and any caveats live in `../.clinerules/20-index.md`, so these files stay purely
generated.

> Note: these patches are a **coaching reference**, not something to `git apply`
> into a working copy.
